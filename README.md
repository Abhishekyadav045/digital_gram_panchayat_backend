# Digital Gram Panchayat Backend

Backend API for Digital Gram Panchayat Management System.

## Features

- User Authentication
- JWT Authentication
- User Registration/Login
- Complaint Management
- Certificate Management
- MongoDB Database Integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Installation

Clone repository:

git clone your-repository-link

Install dependencies:

npm install

Create .env file:

PORT=5000
MONGO_URI=your_database_url
JWT_SECRET=your_secret_key


Run server:

npm start
